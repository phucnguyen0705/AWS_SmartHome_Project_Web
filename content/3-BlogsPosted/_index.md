### [Blog 1 - Amazon EMR on EC2: Optimizing Monitoring & Debugging with 5 New Features](3.1-Blog1/_index.md)
This blog shares practical insights on 5 new features in Amazon EMR on EC2 (CloudWatch Log Streaming, Per-Step S3 Logs, Live UI Console, Direct Mapping of EMR Steps to YARN App IDs, and Custom Metrics). It simplifies monitoring workflows, eliminates complex Proxy/Bastion Host setups, and optimizes operating costs for Big Data workloads.

### [Blog 2 - AWS Amplify: A Lightweight Choice to Host Websites for Demos & Workshops](3.2-Blog2/_index.md)
This blog highlights AWS Amplify Hosting as a streamlined solution for rapidly deploying Demo/Workshop websites without complex S3, CloudFront, or Route 53 setups. It also covers the new integration of AWS WAF (Web Application Firewall) to easily protect web apps with just a few clicks.

### [Blog 3 - Modernizing Lambda + S3 Workloads with Amazon S3 Files](3.3-Blog3/_index.md)
This blog explores an alternative to traditional data processing workflows between AWS Lambda and S3 using Amazon S3 Files. By mounting S3 Buckets directly via VPC Endpoints, developers can completely eliminate temporary `/tmp` transfer code, resulting in cleaner codebases and avoiding disk overflow when handling large files.
